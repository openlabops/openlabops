# lab-TOOLS(1) - Unified Operations TUI Console

## NAME
`lab-tools` - Top-Level Unified Operations Console

## 類別 (CATEGORY)
> **[日常運維 App (Post-Installation Operational App)]**

## SYNOPSIS
```bash
lab-tools
```

## DESCRIPTION
`lab-tools` provides an interactive curses/ANSI terminal menu for operators, unifying:
1. Status Dashboard (`lab-status`)
2. Node Management (`lab-node`)
3. SSH & Key Lifecycle (`lab-ssh`)
4. Declarative Backup (`lab-backup`)
5. Configuration GitOps (`lab-config`)
6. Package Upgrades (`lab-upgrade`)

It requires zero external dependencies, functioning over raw standard library terminal interfaces.
